CONTAINER FEEDER REMAKE — SCOPE / COVERAGE

Replace the original static cargo mesh from scratch with an original detailed
coastal container feeder. Keep all other FutureOps assets intact.

Model: fair hull stations, bulbous bow, raised forecastle and bulwarks, stern,
shaft/propeller/rudder assemblies, cambered deck, hatch coamings, cellular cargo
stowage and lashing bridges, accommodation/bridge, stairs and railings, lifeboats
and davits, anchors/windlasses/bollards, navigation equipment, baked weathered
surface maps, section-aligned damage geometry, purpose-built LODs and colliders.

Native unit: a new stable ShipDefinition/jsonKey using cloned native ship systems;
buoyancy compartments, propulsion, native command/pathfinding AI, host authority,
network identity/transform, damage/flooding/sinking, wake/sound references.
Unarmed cargo configuration; no invented custom ship simulation.

Deliverables: editable Blender source, FBX/material textures, visual comparison
views, static asset-pack replacement, native Blueprinter .nobp registration,
mod resource integration, export/prefab/reference/assembly verification.

Evidence boundary: offline model/bundle/native graph checks are mandatory.
Deployment, actual sailing, impacts/sinking, save/reload and multiplayer must be
reported separately; no claim of live acceptance from static checks.

Reference direction: original coastal feeder informed by working-vessel layout;
not a reproduction of a copyrighted ship drawing.
