Weather bundle source recovery for Boscali Summer 0.2.14 (2026-11-17)
==================================================================
The missing shader sources and Unity import metadata were recovered from the
successful Unity compiler project retained for the shipped weatherrain.bundle.
The retained compiler output and release bundle match SHA-256:
2d70d46af6801c51ba69c2161ba04d64b729400f1ebf650919af0e83f8bc362a

All compiled shader inputs are now present in this directory:
CanopyDroplets.shader, CanopyRain.shader, FlightCloud.shader,
FlightCloudComposite.shader, Ocean.shader, SkyGlow.shader, SkyGlowOver.shader,
SunDisc.shader, SunShafts.shader, TerrainDetail.shader, TerrainRain.shader.
Existing Ocean.shader and TerrainDetail.shader match the compiler inputs after
normalizing CRLF/LF line endings. Their source content was not replaced.

The original compiler helper is restored at nomodkit/mods/boscalisummer/tools/Compile-WeatherAssets.ps1.
Its Unity editor build source is embedded in the script. It uses Unity
2022.3.62f3 and builds for StandaloneWindows64 with chunk-based compression.
The historical droplets_mask.tif and rivulets_mask.tif inputs were explicitly
excluded by that helper and are not included in the restored source set.
Other shaders now in this source directory may be used by separate bundles;
this source restoration does not claim a byte-identical fresh rebuild.

Canopy effects derive from RainyGlassShader by toadstorm, adapted for Boscali's
URP rendering and per-pane heightfield simulation; see NOTICE.txt and LICENSE.
The project source archive distributed beside this release includes the
adapted shader sources and build helper under their applicable notices.
