Cinematic rendering assets - Boscali Summer
=========================================
Updated: 2026-11-17

Source/CinematicStreak.shader is original code written for this project.
It contains highlight extraction, an 11-tap horizontal filter, scene composition
and an additive full-screen drawing pass. The shader uses Unity's supplied
UnityCG.cginc; no external shader source or LUT texture is copied into it.
Its existing import metadata is retained.

cinematic.bundle contains exactly this one shader, built for Windows with
Unity 2022.3.62f3. It has no texture assets or third-party LUT dependency.
Cinematic colour grading uses the game's native URP volume controls; exposure,
G-LOC and native rendering remain owned by the game.

Rebuild: powershell -File nomodkit/mods/boscalisummer/tools/Build-CinematicAssets.ps1
Output: modules/Effects/Assets/cinematic.bundle
The builder runs in an isolated Unity project and reloads the built player
bundle before testing its four supported passes. Checks are mandatory:
- Synthetic warm-light rendering: horizontal spread and source hue, no vertical
  or corner haze, finite output, preserved brightness, zero strength restoring
  the source image.
- Eighteen GPU parity cases compare scene-copy composition with additive drawing:
  ARGBHalf and RGB111110Float; 1x and 8x MSAA; 256- and 260-pixel widths;
  zero and nonzero strength; plus 1920x1080 at 8x MSAA for each HDR format.
  These check finite output, RGB agreement within two representable steps,
  preserved destination alpha and a visible streak when enabled.
The fixture shaders in nomodkit/mods/boscalisummer/tools/CinematicAssets are Editor tests and are excluded
from cinematic.bundle. Results and measurements stay beside the scratch project.
