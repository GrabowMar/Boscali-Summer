BOSCALI RADIO STATIONS
======================

Add a station in three steps:

1. Create a folder here using the station name.
2. Put .ogg or .wav tracks directly inside it.
3. Open RAD on the maximised map and press RESCAN.

Files placed directly in Music appear under LOCAL.

Agrapol FM, Maris Network, and Base Broadcast use Nuclear Option's installed soundtrack
at runtime; no game audio is copied into these folders. You can add your own tracks beside
station.png without replacing the built-in soundtrack entries.

station.png is displayed in the current-station header and channel list. Custom stations
may use a square transparent PNG up to 256x256 pixels and 256 KiB. Missing or invalid icons
fall back to the station's compact two-letter badge.
